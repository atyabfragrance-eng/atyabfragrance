ATYAB FRAGRANCE - Supabase Setup

1) Import products:
   Supabase > Table Editor > products > Import data from CSV
   Upload: products_supabase_import.csv

2) Add public read policy:
   Supabase > SQL Editor > New query
   Paste/run the code from: SUPABASE_RLS_POLICY.sql

3) Get anon key:
   Supabase > Project Settings > API > Project API keys > anon/public key
   Copy it.

4) Open supabase-config.js and replace:
   PASTE_SUPABASE_ANON_KEY_HERE
   with your anon/public key.

5) Upload final website files to GitHub.

Safety:
- If Supabase is empty, policy missing, or key not added, website will still show default products.
- Existing buttons and pages are kept unchanged.
